# Quick start

*Planned.* smaltai isn't built yet. When it is, this page gets you from nothing to an agent working in smaltbi in a few
steps:

1. Run a gateway on your machine and allow the smalt apps to reach it ([Gateways](gateways)).
2. Register it in smaltbi's AI settings: its address and format. There is no field for a key.
3. Choose what the agent may see and do ([Grants](grants)), and start a chat.
